Нажимаешь <kbd>⌘</kbd><kbd>⇧</kbd><kbd>V</kbd> в любом приложении, и появляется окно со всем, что ты копировал: текстом, ссылками, картинками, цветами и файлами. Находишь нужное, жмёшь <kbd>↵</kbd>, и запись вставляется туда, где ты работал.

## Возможности

- **Мгновенный поиск** по всей истории. Регистр не важен, кириллица тоже, слова ищутся в любом порядке.
- **Автоопределение типа**: текст, ссылка, картинка, HEX-цвет (с превью образца), файлы из Finder.
- **Превью справа**: полный текст, крупный образец цвета, картинка, домен ссылки, список файлов, а также метаданные (приложение-источник с иконкой, дата, размер, сколько раз использовано).
- **Автовставка** в активное окно (эмуляция <kbd>⌘V</kbd> через Accessibility API).
- **Закрепление** важных записей. Закреплённые не удаляются при очистке и лимите.
- **Приватность**: пароли из 1Password, Bitwarden и Связки ключей не сохраняются (конвенции [nspasteboard.org](http://nspasteboard.org)). Есть пауза записи.
- **Нативный вид**: окно с эффектом стекла (`NSVisualEffectView`), тёмная и светлая темы, работает поверх полноэкранных приложений и на всех Spaces.
- **Живёт в строке меню**: иконки в Dock нет, в фоне приложение почти не потребляет ресурсов.

## Горячие клавиши

| Клавиши | Действие |
|---|---|
| <kbd>⌘⇧V</kbd> | открыть / закрыть (меняется в настройках) |
| <kbd>↑</kbd> <kbd>↓</kbd> | навигация |
| <kbd>↵</kbd> | вставить в активное окно |
| <kbd>⌘↵</kbd> | только скопировать |
| <kbd>⌘1</kbd>…<kbd>⌘9</kbd> | быстро вставить N-ю запись |
| <kbd>⌘P</kbd> | закрепить / открепить |
| <kbd>⌘⌫</kbd> | удалить запись |
| <kbd>⌘O</kbd> | открыть ссылку в браузере |
| <kbd>Tab</kbd> / <kbd>⇧Tab</kbd> | переключить фильтр |
| <kbd>⌘,</kbd> | настройки |
| <kbd>Esc</kbd> | очистить поиск / закрыть |

## Архитектура

```
src/
├── core/                    # чистая логика, без UI и ОС → покрыта тестами
│   ├── ClipItem             # модель данных, классификация, хеши
│   └── ClipStore            # SQLite: схема + миграции, дедупликация, поиск, лимиты
├── app/
│   ├── AppController        # связывает хранилище, буфер, ОС и QML
│   ├── ClipModel            # QAbstractListModel для списка
│   ├── ClipboardWatcher     # отслеживает изменения буфера
│   ├── ClipImageProvider    # картинки и иконки приложений для QML (в фоновых потоках)
│   └── TrayIcon             # иконка в строке меню
├── platform/
│   ├── Platform.h           # тонкая абстракция над ОС
│   ├── Platform_mac.mm      # Objective-C++: Carbon hotkey, CGEvent, NSPasteboard, NSVisualEffectView
│   └── Platform_stub.cpp    # заглушки для других ОС
qml/                         # UI: 16 компонентов, дизайн-токены в Theme.qml
tests/                       # Qt Test: хранилище и классификатор
```

Решения, которые стоит отметить:

- **Поллинг `NSPasteboard.changeCount`** раз в 350 мс. В macOS нет уведомления об изменении буфера, а сам счётчик очень дешёвый: данные читаются только тогда, когда он изменился.
- **Дедупликация через SHA-1** содержимого и `INSERT … ON CONFLICT(hash) DO UPDATE`. Если скопировать то же самое повторно, запись поднимается наверх, а не дублируется.
- **Поиск по кириллице без учёта регистра.** `LIKE` в SQLite приводит к нижнему регистру только ASCII, поэтому при вставке в отдельную колонку `search_text` пишется текст, приведённый к нижнему регистру через Unicode-aware `QString::toLower()`.
- **Отдельное SQLite-соединение на каждый поток.** Картинки грузятся в потоках QML image loader, а `QSqlDatabase` нельзя использовать из разных потоков.
- **Схема с версионированием** через `PRAGMA user_version`, база работает в режиме WAL.
- **Иконки приложений-источников** рендерятся из `NSWorkspace` один раз и кешируются в БД.
- **Ни одного файла-картинки в UI**: иконки нарисованы как SVG-path через `QtQuick.Shapes` (CurveRenderer), иконка в строке меню рисуется `QPainter`'ом как template image.

## Сборка

Нужны macOS 12+, Xcode Command Line Tools и Homebrew.

```bash
brew install qt cmake ninja

cmake -S . -B build -G Ninja \
      -DCMAKE_BUILD_TYPE=Release \
      -DCMAKE_PREFIX_PATH="$(brew --prefix qt)"
cmake --build build
ctest --test-dir build --output-on-failure   # тесты

open build/ClipStash.app
```

**CLion:** открой папку проекта, затем Settings → Build → CMake → CMake options: `-DCMAKE_PREFIX_PATH=/opt/homebrew/opt/qt`.

### Разрешение «Универсальный доступ»

Без него всё работает, кроме автовставки: запись просто копируется. Выдать разрешение можно в Системных настройках → Конфиденциальность и безопасность → Универсальный доступ → ClipStash.

> При разработке каждая пересборка меняет подпись приложения (ad-hoc), и macOS может «забыть» разрешение. Тогда удали ClipStash из списка и добавь заново, либо подписывай сборку постоянным self-signed сертификатом.

### Готовый `.dmg`

```bash
"$(brew --prefix qt)/bin/macdeployqt" build/ClipStash.app -qmldir=qml -dmg
```
